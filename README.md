# MOK Portfolio
Using AI tutor I built  clean, responsive personal developer portfolio website built with semantic HTML5, CSS3, and vanilla JavaScript.

## Features
- **Responsive Navigation:** Desktop flex navigation bar that collapses into an accessible mobile hamburger menu below `768px`, complete with `aria-expanded` state updates and automatic menu closing on link selection.
- **Hero & About Sections:** Centered Flexbox hero banner and a two-column About section that stacks smoothly on smaller screens.
- **Responsive Project Grid:** Auto-fitting CSS Grid layout (`repeat(auto-fit, minmax(280px, 1fr))`) with uniform card thumbnails and aligned repository buttons.
- **Accessible Contact Form:** Semantic form labels paired with clean, mobile-friendly inputs.

## Built With
- HTML5
- CSS3 (Flexbox, CSS Grid, Media Queries)
- Vanilla JavaScript (DOM manipulation & event listeners)

## Learning Process & AI Attribution
After completing an introductory bootcamp, I built this portfolio as part of my self-directed learning to strengthen my core front-end fundamentals. 

During development, I used an AI assistant in a **guided tutor mode** (similar to freeCodeCamp's step-by-step approach) to review my code, explain concepts like Flexbox alignment, `object-fit`, CSS Grid `auto-fit`, and accessible HTML structure, and walk me through implementing each section myself.
